# 开场与卷结构候选

主会话按授权范围填写实际内容，不以占位词交stage-submit；未规划后卷不编。正式采用另按作者确认流程。

## 开场卡 / design.opening_promise

- 当前视点、时空与人物处境：
- 已在发生的重大事件；怎样改变核心矛盾：
- 眼前所求/想保住什么、主要阻力、失败损失：
- 关键选择、立即后果、引向主线的问题：
- 开场读者必须知道的因果；可暂未知的部分及公平边界：

## 真实时序与揭示顺序 / outline.opening_sequence

|事实/背景|真实发生顺序|当前POV是否知道|首次可见证据|何时揭示/当前触发|改变何种判断/关系/行动|未结边界|
|---|---|---|---|---|---|---|

## 每卷目标卡 / design.volume_goals 与 outline.volume_progression

每卷各填一张；局部任务引用卷ID及现有卡，无授权的部分明确不适用理由。

- 卷ID、范围、开局状态：
- 核心主体、可验结果、成功判据、失败判据：
- 主要对抗与限制、不可兼得选择、成本：
- 故事单元/章区间及因果承接：
- 大高潮怎样检验目标；卷末成功/失败/惨胜/转化的可能新状态：
- 与全书主线的联系、下一卷压力、跨卷未结项：

## 大小高潮与期待兑现 / outline.peaks_payoffs

覆盖起点每卷至少1核心大高潮、2不同局部高潮、2种兑现；可按范围与篇幅提出有理由的调整，交独立语义审查，不冒称研究最优频率。规划只填planned及结果候选，不填已兑现。实际章写后补当前正文引用和真实状态。

|卷/事件ID|章区间|大/小高潮/兑现类型|期待与前证出处|阻力/选择/代价|计划改变何种条件|实际结果/余波及正文证据|状态/未结边界|
|---|---|---|---|---|---|---|---|

## 当前章场执行 / scene_plan.narrative_function

- 当前章与场的叙事职责；所承接卷卡/事件ID：
- 本场独占plot及detail_requirements实际ID/可见义务：
- 跨场/整章义务及整章核验位置：
- 伏笔setups来源与先后；人物可知/读者已知边界：
- 善后与下一场因果；当前未写/未决项：
