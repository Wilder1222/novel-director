# 编辑审查与重写策略

## 分层编辑

1. 结构性问题：本卷/章节目标成立吗？转折由行动造成吗？
2. 连续性问题：日期、岁数、物证、人物已知信息、时空版本可追溯吗？
3. 情感性问题：冲突来自人物价值选择吗？关系变化有中间台阶吗？
4. 场景性问题：目标、阻碍、危机、行动、结果、情绪后续是否必要？
5. 文本性问题：对白辨识度、重复解释、风格漂移、节奏是否合适？
6. 文字性问题：错别字、病句、冗余词句。

## 六维评分与证据

每维 1-5 分：`情节目标 / 因果逻辑 / 人物动机 / 线索公平 / 叙事声调 / 情感强度`。对每项评分提供具体片段或项目记录引用，并说明“缺失证据”还是“存在反证”。

**错误**：明显违反锁定事实，需修复。
**风险**：存在另一合理解释，提出必要取证。
**审美建议**：多方案并列，不否决作者偏好。

## 缺陷优先级

P0：破坏世界规则、核心年龄、旅行窗口、信息可得性、因果闭环；P1：主角无动机、章节没有变化、主要反转不公平；P2：对白重复、节奏失衡、描述堆叠；P3：格式文字瑕疵。每次先处理 P0/P1，再润色词句。

## 修订流程

生成 `issue / evidence / severity / proposed_fix / impacted_chapters / requires_author_approval`；给出最小修复和结构性重写两种方案。保留初稿与修改前后差异；没有作者指令，不跨章节大幅改动锁定情节。

## 防止审校幻觉

AI 编辑可能错过作品最大问题（Rashkin et al. 2025），所以关键卷必须安排人工阅读。确定性脚本只证明符合其明确定义的检查项，不能把“脚本通过”当作小说已具备出版品质。
