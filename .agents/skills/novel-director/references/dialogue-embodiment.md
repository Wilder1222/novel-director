# 对白、语气与行动共同创作

交流段、场景及整章的展开/概述和对白密度同时按[小说叙述节奏](dialogue-density.md)执行：不设比例或句数配额，保留有作用的连答，不能靠逐句动作稀释，也不以密度为由擅改已采纳台词。

每个人说的话都来自当前处境。先看他对谁说、此刻想争取或回避什么、知道什么、受到什么剧情压力；再结合既有性格/声线、情绪与身体状态、关系亲疏和权力差异，决定措辞、语气词、停顿、表情/目光和动作。它们是同一次反应，不是写完台词后另贴表情和动作。

关键变化处写足，普通应答写轻。语气词可以表示请求、试探、坚持、缓和或亲近；同一个“吧”放进命令、请求和让步中力度不同。依人物、时代和语域选择，不句句加啊/呢/嘛，不拿口癖代替人物。正式回答、紧急命令、沉默与克制均可成立。外表笑、嘴上拒绝可以是有依据的掩饰，不自动判为情绪矛盾；不能单凭表情断定真实私心。

## 人物关系、任务、性格和说话习惯

先辨认当前对谁说，再结合本人当前任务/goal、单向relationship_view、性格/价值与voice、常态语气、最近观察到的回应及身体情绪，决定称呼、礼貌/亲疏分寸、词汇句长、直说/请求/协商/回避和当场语气。关系看法不证明对方也亲近；换对象可以换说法，不等于人格重置。谨慎不必总迟疑，强硬也能请求，温和人物面对危险也可以喊短命令；不要把这些依据写成台词里的自我介绍。

主会话从当场可知的人物资料整理`instances[].speech_style`，不用作者填表。它只属于当前instance_id、history_id与年龄实例，不能把另一历史/未来习惯填进共享profile或回退给当前人。原profiles.voice/values/limits、goal与relationship_view继续使用。没有新字段不自动造口癖，也不自动迁移/确认作者设定。配置片段示例（不是完整config）：

```json
{"speech_style":{"personality":"谨慎但能拒绝","baseline_tone":"平常简洁温和","verbal_habits":"先问当前问题，不念性格标签","catchphrases":[{"phrase":"稳着点","when":"熟悉搭档急于行动，想劝其放慢时","avoid_when":"正式交接、陌生对象，或当前任务需要紧急短令时"}]}}
```

speech_style可为空对象，三个文字字段均可省略；catchphrases可省或为空，最多8项、phrase去首尾空白后唯一，每项phrase/when/avoid_when均为非空文字。未知字段/类型拒绝。口癖可使用、变体或收住，不能按出勤率检验人设，也不能给所有人同一句；主会话应标明来源与候选/已确认范围，不因结构验证通过就确认Canon。

工具只把当前实例speech_style给该actor，resolve/compose/整章不自动得到原始私密样式或关系总账。人物实际采纳的speech才保留到成稿，narrator不能按人设印象补口癖。编辑由主会话提供当场安全对照，零命中也审关系/任务/声线和口癖使用条件；缺资料保留未知，未出现口头禅不判错。新增R049–R052是原创教学例，包含对象分寸、人物标签、口癖过用和紧急任务下不用口癖。

## 对白中的语气、停顿与断续

对白需要时可用省略号“……”表现迟疑、话尾未尽或吞回去的话，用破折号“——”表现骤然中断或改向；也可用“我、我没答应”式结巴、“别动！别动！”式强调重复、“不，不是明天，是今天”式改口。先看目的、对方反应、压力与声线，再选形式。它们不是固定的情绪编码：不能见省略号就认定害怕，见重复就认定撒谎，也不把稳定口吃当怯懦或笑料。

对话语句过于平整、人人同样断续，以及无功能的省略号/问叹号堆叠都要审。可比较“去掉或换掉这一处会怎样改变节奏、坚持、遮掩或关系力度”，用实际上下文说明。没有这些符号仍可自然，紧张也可克制；“收到。”“退后！”无须凑结巴或省略号。标点排版遵循当前书规范，扫描不会归一化或替换原字符。

人物在speech中提出这些形式；resolve不代写，compose与整章保留已采纳speech的原始符号、重复次数和顺序。不为“去重”“统一标点”擅自抹平，需调整仍回人物重提/显式修订。反AI味检查提供对白内的三类中性定位，不按数量或缺少符号判断好坏；零命中仍读完整交流。新增原创对照R043–R048涵盖迟疑、骤断、机械结巴、有作用的重复、标点堆叠与改口，不能替不同语境套改。

## 同一条执行链

1. 主会话准备现有public_brief、人物profile/voice、目标、relationship_view和已观察事件。把影响交流的空间/任务/时限及已知伤痛/情绪写入各自可知材料；缺的信息保留未知，不补关系或道具，不把主线秘密发给演员。
2. 核心人物与普通角色都以speech和action_intent共同提案。speech包含所选措辞/语气词/标点节奏；action_intent可提出可听语气、停顿、表情/目光、自己的动作及相对发言先后。不是要求每轮填写全部要素，不替对方作决定。private_intent仍是私有动机。
3. resolve按身体、空间及已有事件裁定。把实际认可的可观察语气、表情/动作及发言先后写入result；失败则拒绝，不能把“想拦住”直接写成“拦住了”。拒绝会推进轮次，需在后续允许轮次/新排练改提案。speech逐字来自人物，不由主线改写。
4. compose仅接收reader_visible且POV实际在observers中的事件，结合speech/result组织自然正文。整章scene.accepted_events沿用同一投影，仅含id/actor_id/speech/result；不传原始action_intent、private_intent或他人专属观察。允许的本视角内心仍按原场景单独限权，不能由汇编新造。
5. 已采纳speech按连续原串、顺序和重复次数锁定。动作安排在原串前后；不能把一个长speech拆为两段引号再插动作。需加语气词、改词或拆句，回人物重提/显式修订，不为“自然”暗改。关键行为与时序的语义保留仍要人工/模型读例，不靠字符串锁保证。
6. 主会话给审查者当前正文、当场可知材料及上述过滤后的事件作对照，不能转发排练总账或人物私密动机。writing_spec必审dialogue_context与dialogue_embodiment；逐位实际发言者核语境/声音/联合反应。反AI味八类中的stock_gesture、flattened_voice同核，即使字面零命中也审。缺对照或难判就标uncertain/unknown，不虚构已核过。未配置规格的旧项目不冒称已通过这些门槛。

## 原创教学例（未锁定草稿）

下面是新造的工具教学情境，不是作者小说、来源作品摘录或唯一正确改法。改写权不覆盖已采纳speech。

**赶船的请求。** 雨夜渡口，严青禾只有半份船资，急送药给父亲，不愿求人怜悯；谨慎船工柳南星尚不知病情，乘客正在催船。

严青禾摊开手，湿铜钱粘在掌心，只够一半船资。

“能先记着吗？”

“明早再过。”

“药等不了呀。”

柳南星脚下的缆绳停住。他看见她怀里那只纸包，底角已经湿透了。

“谁等？”

“我爹。”

船头又有人催。柳南星把踏板往岸边送了半尺：“上来吧。坐篷里。”

“呀”贴着急切请求，“吧”伴随让步；解缆暂停和送踏板属于同一任务并改变局面。中间连续对答无附加动作。船工先看到药包、再追问，未预知病情。若声线/年代不宜用这两个词，可在人物提案阶段换法，不把例子当古代语言考据。

**同句不同压力。** 已知林照受伤、正带同伴躲追赶，左手仍能推门：“没事。走。”林照把渗血的右袖藏到身后，用左手推开门。伤势、遮掩与催走构成同一反应，不必旁白再宣布他很担心。同句若发生在无伤的日常寒暄，就不能沿用藏袖推门；必须依实际现场另选表达，不能为鲜活新增伤势。

**拒绝与动作反衬。** 已知许清和愿暂时让客人避雨但不愿接待长谈，门口狭窄：“别待太久。”许清和侧身让开门。嘴上设限、身体让路可同时成立，不改成“笑了就不可能拒绝”，也不据此断言爱意。

**身体限制。** 已知江砚右腕伤、仍在守门，门闩已落好：“先别开门。”江砚用左手抵住门板。不能为了强情绪写成右手猛拍重物，也不能让他的命令直接成为另一人已服从的结果。

**沉默。** 已知沈竹不愿交出钥匙，当前只裁定她握紧钥匙、没有作答，POV看得到。可写沈竹没有回答，钥匙仍攥在掌心。不补“她心中已经答应”，不强加一句台词；如果动作未被观察到，也不能收入正文。

**正式与紧急短答。** 交接确认只答“收到。”；火势逼近时喊“退后！”均可不加语气词或伴随动作。只有上下文不足以辨认说话者、语气或关键选择时才补必要信息，不因简短判呆板。

反例：每句“焦急地皱眉”“认真地点头”加啊/呢/嘛，动作彼此可换、对方反应未改变后续，还用旁白重说情绪。问题在于脱离场景与作用，不是这些字词一律禁用。

## 旧工作与核验边界

工程检查确认数据过滤、原句锁与漏审阻断；语义审查确认具体语境中是否成立，仍不等于外部读者或作者批准。研究及其适用范围见仓库research/2026-10-24-dialogue-embodiment.md；独立Director包以本页自足执行，不依赖仓库研究目录。
