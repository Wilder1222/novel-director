# 定向修订学习闭环

一次只练一个主要弱项。先写自己的意图，再看反馈，不让外部意见替作者决定想写什么。

1. 阅读合法可用样本，记下行动、信息和关系的变化，而非摘录流行措辞。
2. 写一个原创短场景；提出明确问题，比如‘这次愿意合作由哪一个动作促成？’。
3. 审稿保留原句，区分看到的现象和解释。优先讨论最大结构问题。
4. 锁定保留项与修订范围；提出两个不同改法，选择最符合本章意图的一种。
5. 生成补丁，重看前后。先检查是否解决原问题，再查有没有抹掉声音、伏笔、情感复杂性。
6. 同一作者/模型自评标self_review，真实独立反馈另存；判断不确定就保留uncertain。
7. 在下一次不同场景复练，不重复本次答案，不靠固定天数或总分保证进步。

训练记录字段建议：weakness、intended_reader_experience、observed_evidence、chosen_intervention、preserved_values、before_after_refs、reviewer_origin、remaining_doubts、next_transfer_task。
