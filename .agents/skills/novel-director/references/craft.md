# 叙事结构与章节编排

## 不同尺度使用不同工具

- 作品级：一句话命题；人物欲望（想得到什么）与需要（必须改变什么）；不可兼得的终局选择。
- 分卷级：开局状态 → 触发 → 第一次承担后果 → 中点认知改变 → 最低点 → 主动选择 → 本卷谜题兑现。
- 单元级：一个可完成的任务、三种障碍、一次由角色行动引发的局势逆转、阶段性答案。
- 场景级：目的 → 抵抗 → 变化 → 反应/决定；可参考 Story Grid 的事件、递进复杂化、危机、高潮、结局。
- 句子级：视角感知、动作与选择、不言自明的情绪。不要让所有角色拥有相同的语气。

## 倒推与铺陈结合

先写终点和核心真相，逆推关键节点；在场景上用“因为…所以…”而不是“然后…然后…”。时间悬疑可用 DOC 方法的详细大纲控制，但不应把所有段落写成公式。

## 每个章节的最小交付

一章必须至少满足：
1. 视角人物此刻要什么、阻碍是什么；
2. 行动或事件改变了情况（含角色的理解、关系或情绪）；
3. 该变化与主线、人物弧线、悬疑链至少一项有因果连接；
4. 下一章为什么有必要存在。

断章可使用行动未决、信息冲突、选择后果、情感余韵。不要机械制造每章一惊吓。

## 双 POV 策略

按“谁面对最难选择、谁最有信息偏差”选择 POV，而不是强制男女主轮流。每场景原则上限知一个视角，跨视角需明确场景分隔。人物知道的消息与读者知道的消息不一定相同。

## 长篇过程

全书大纲 → 单卷 4-8 故事单元 → 单元章卡 → 2-5 章连续试写 → 结构回顾。完成短期弧线后再推进下一部分，不能因为目标总字数而创造冗长的调查往返。
