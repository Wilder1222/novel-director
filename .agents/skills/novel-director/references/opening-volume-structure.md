# 开场与分卷结构

作者当前要求：重大剧情和冲突开场，随后缓缓铺开、回头细说；每卷有核心阶段目标，安排大小高潮和爽点。章仍3000–6000 LN，剧情默认500–2500。按任务范围填写[产物模板](../assets/opening-volume-plan.md)，主会话代填，不要求作者处理JSON；局部任务只引用已有卷卡和当前职责，未授权全书时不编造后卷。后台计划不自动成为正式设定。

## 开场卡：先发生，再逐步理解

以正在造成损失、机会或秩序变化的核心事件切入。当前人物/视点、眼前目标、阻力、失败损失及一次实际选择/后果应可理解，并留下与主线相关的阅读问题。“重大”取决于它改变本书核心矛盾的程度；不能用一串陌生势力、人名、爆炸或旁白预告冒充。开场冲突可以揭出更大问题，不必立刻交代全部世界观，也不强制序章。

作者端保存真实因果时序，读者端另排揭示顺序。每段前史/背景由当前行动、证据或情绪触发，并改变当前判断、关系、行动选择或旧证据含义。保护视点：不能故意省略其做当前决定必知的信息来骗读者。揭晓不临时添万能能力、无痕内应或从未可见的关键证据。回头细说默认因果补叙；确需跳转叙事时间时标清时空另作设计，不倒排现有assembly场景来绕过时间检查。

## 卷目标与高潮兑现表

每个规划卷有一个核心阶段目标，写明主体、具体结果、成功/失败判据、主要对抗、关键选择、成本、卷末新状态及其与主线的因果联系。“成长”“见识世界”“换地图”不足以验目标。单元有局部目标，解决后改变下一单元条件。

每卷安排核心大高潮、不同局部高潮及多种期待兑现。当前模板以至少1大、2小、2种兑现为覆盖起点；这是落实“大大小小”的可调整设计下限，不是作者指定数字、普遍最佳频率或每章配额。章区间依卷长、因果与铺垫确定，短范围计划引用现有安排；不足或不适用须说明并进入语义审查，不能空填“已安排”。大高潮检验本卷核心目标和关键选择；局部高潮解决一个真实问题并改变后续条件。一个事件可兼任高潮/爽点，分别交代功能，不能复制同一战斗凑表。

每个兑现登记：期待是什么、读者何时获得前证、如何积累、面对何种阻力、人物主动选择、付出什么、计划章区间、实际结果/情绪余波、未结边界。能力验证、聪明脱困、有限公正、判断被证实、关系尊重和自主均可兑现；旁人反复震惊、敌人集体失智、无铺垫无代价升级不足以成立。胁迫与伤害不能直接证明爱情或正义。

结果可以胜利、失败、惨胜或目标转化，必须据实结算阶段目标，保留代价；失败不能冒称达标，也不抹去选择、真相或局部能力兑现。高潮后处理善后、资源、伤势、关系与认知变化。安静恢复章可推进这些状态，不强制章章反转。全书伏线可以跨卷，卷内承诺、暂缓理由、后续追索分开。

## 从计划到实际成稿

1. `design`必交`opening_promise/volume_goals`；`outline`必交`opening_sequence/volume_progression/peaks_payoffs`。完整作品和索引均须有内容，不以标题替代。各criterion/item的真实不同执行者审查全覆盖，revise/unknown/漏项阻止推进。
2. `scene_plan.narrative_function`说明当前单元属于开场、补叙铺陈、局部高潮、卷高潮或余波，可兼任。为本场所需行为写`writing_spec.detail_requirements`，例如`{"id":"opening_conflict","scope":"P1","criterion":"本场眼前目标、阻力、主动选择与可见后果成立"}`；P1必须是该书实际存在且完全属于当前场景的plot，不能原样抄ID。
3. 自定义chapter或跨场plot义务只在整章核；现有局部compose不会收到它们。需第一场执行的开场义务放到第一场独占plot；若剧情本来跨场，拆分符合因果的单元或仅把本场可执行部分分配给独占plot，整章仍核总义务。不得为传规则提前泄露后场真相。`setups`另用既有实际来源/位置校验支持前证，不把泛用detail文字当作已经有伏笔证据。
4. 抽象已确认偏好可进`writing_profile.rules`；候选模板[opening-volume-profile](../assets/opening-volume-profile.json)不可直接标confirmed。只有本次明确授权的规则、无剧情秘密才投影，原话/calibration不传演员。narration_origin明确区分tool_default与author_confirmed，默认视角不得冒称作者选定。profile只到compose/整章汇编，actor/resolve不接收。
5. 正文仍由真实parts汇编并计数；逐项review必须引用正确plot/整章的当前原文，缺项、错scope、partial/contradicted不放行。`editorial.narrative_execution`按当前章职责审实际开场/补叙/高潮/兑现，而非强迫过渡章也做卷高潮。规划表先标planned，只有真实正文与复核证据支持才改为兑现/失败/延期；不得预填已完成。

结构程序只验证存在性、覆盖、版本、引用和时序；文学成立与否由真实语义审查判断，仍可能漏错，同模型评审不是外部读者或作者批准。
