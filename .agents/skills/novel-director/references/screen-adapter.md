# 小说 → 剧本 / AIGC 分镜的可选适配器

只有用户明确要求改编时才启动；小说正文的首要目标仍是可读性，不将其写成分镜说明书。

## 输出契约

对于每一处确认的场景，导出：
- `scene_id`、`source_chapter_id`、`history_id`、`in_world_at`、地点、昼夜、参与角色及版本；
- 角色外观、服装、情绪、动作在相邻镜头中的连续性要求；
- 场景目标、冲突、变化、重要道具、伏笔保密级别；
- 可视化行为与必须另行处理的内心叙述；
- 关键镜头建议、环境/角色/道具资产需求和声音设计提示。

## 隐私与授权

电影项目的素材库或图像参考需要通过用户明确许可的来源读取，不假定已经连接 FRAME 或其他资产系统。不自动生成图像、视频或发布作品。未经作者允许不把尚未揭示的全书真相输出到面向观众的镜头方案中。
