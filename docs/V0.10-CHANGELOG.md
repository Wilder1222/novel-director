# v0.10：篇幅、细节、反AI味与参考索引

Director0.10.0 / Studio0.4.0，承接0.9阶段作品与核验。现场已装0.9.0阶段版不含本轮writing_spec；用新版本刷新避免同版缓存混淆。

- 新正文/修订先制定章、剧情、场景parts硬范围，父子/共享场景预算先验可行，实际全文覆盖映射重算有效字。人物选择、事件过程、具体细节、视角、情感余波与铺垫有逐项原文验收。数字是可调整工程规格，不能跨题材硬套。
- 成稿可回原始有序parts，工具逐字编译偏移/SHA；支持整章重写和转场归属。修订预检失败不写半应用；Unicode变化不重签旧排练，组章中断恢复重核正文及同一映射。
- 32条原创反AI味语境对照，八类各4条，有逐条理由及合法保留对照。字面/重复只定位，零命中也做八类审读；需改/不确定阻断出口，问题进入Run修订。正文/语料/保护/检查器/参数漂移使旧报告失效。
- 参考库按作品/版次/题材/状态/阅读方向检索；5部各50章/回合计250达采集门槛，言情47/38未满分别保留，不拼数；另两个0章阻塞候选。采集不冒称全章文学分析。原始来源与逐章身份/URL/正文摘要/计数/语义状态交叉绑定。
- 研究出口可冻结声明书目与reference_samples逐部50和claim_scope；八种意图阶段、独立审查回执、版本失效、作者批准原边界继续有效。旧无writing_spec/未托管流程不强迁移，不称已做本轮验收。
- 发布文本源码LF摘要，但research/samples冻结元数据保留精确字节，避免换行破坏来源链；独立Skill、完整workspace与插件均有可检索portable库，完整包附原始研究元数据。
