# v0.8.0 变化与兼容说明

2026-10-21，Studio0.2.0。研究、方案先于代码完成，见research/。

## 修复

- doctor按当前utf8-lf源码清单核对；历史来源及原文审批的精确字节规则保持独立。
- 新增公开可重建合成测试，覆盖候选审批、引文、角色过滤、定向修订和新增流程。
- 通用参考、练习和新模板不写死某书人物、年龄、日期或穿越上限；不改已有书。
- 学习记录使用项目learning/；公共skill只读。统一Python3.11和命令路径。
- 同章稍后关系结果不提前进入writer记忆。

## 新增

任务checkpoint/resume、按项目注册核心角色、候选/确认文风和题材侧重、整章候选组装、连续3–5章引文审查、宿主观察记录与能力门槛。
插件构建分离工具和作者目录；禁止安装目录内写作品。发布源拒绝符号链接、junction和解析后越界路径。

## 独立复核修复

- 不绑定书身份的legacy核心映射不再因同名ID自动继承；显式role-adopt-legacy核实并绑定当前书。
- checkpoint除manifest外核验候选正文和审稿原字节。
- 整章清单不能覆盖已登记场次；以解析后的时间检查顺序。
- 整章交接采用固定Run身份，最终保存失败后重试不重复创建Run。
- 跨章预算在生成和接收时一致；同一整章宿主门槛和原始回执流程覆盖chapter_compose。

## 兼容与边界

project仍支持0.1–0.4、ensemble配置和记忆仍0.7、Run契约仍0.5；不自动补键或重写旧排练。
缺省无新文风时旧packet结构不变；新增writing_profile会安全失效旧依赖审批/排练，应新建相关流程。
旧映射须明确绑定本书，避免新书同名人物ID串书；不自动覆写旧文件。
没有年龄锚点却声明锚点年龄、或有旅行却缺少显式上限时要求补配置，不猜年代或72小时。

自由文本仍需语义审查；引文真实不等于论证正确；probe不是权限沙箱或远程认证。
异常中断可留下attempt与待核对Run，不能盲目删锁或覆盖。作者原小说和严格人物隔离未在本版验收。
