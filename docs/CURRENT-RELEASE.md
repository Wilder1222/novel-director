人物的措辞、适当语气词/停顿、可听语气、表情/目光及动作共同响应当前场景、剧情目标与压力、性格、情绪身体状态和关系。人物在speech/action_intent中共同提案，主线裁定后才将获准反应及其先后写入result；场景成稿与整章汇编共用POV可见事件投影。行动意图、私密动机与他人专属观察不成为汇编事实。

已采纳speech保持连续原串、顺序与重复；动作置于原串前后，改词/加语气词/拆句须回人物重提或显式修订。必审dialogue_context/dialogue_embodiment，逐位实际发言者核联合表达；八类语境审查同步扩充，语料1.5.0为56条原创对照。无逐句配额，保护沉默、正式/紧急短答、克制与有依据的反差。

人物按当场关系、任务、性格、常态与情绪选择称呼、句式、语气和口头禅；instances[].speech_style只属于当前年龄/历史实例，不回填他人习惯。省略号、骤断、结巴、重复及改口可承载表达，不按符号数量判断。详见[联合创作](../.agents/skills/novel-director/references/dialogue-embodiment.md)。

按[小说对白密度](../.agents/skills/novel-director/references/dialogue-density.md)核交流段、场景与整章的展开/概述、关键反应和时空锚点；不设比例/句数硬阈值，不逐句堆动作稀释。按[自述与成长过程](../.agents/skills/novel-director/references/interiority-progression.md)在相关章卡展开自我判断、练习的尝试/反馈/调整、晋升前中后与有限验证，前证连接后续应用，不强制每章突破。

旧待汇编缺accepted_events需显式新assembly-plan；原生产场景若规格/语料依赖过期，先重建排练、Run及审查，不能仅补字段或重签旧状态。新阶段核验器需显式替代流程并重审上游，不迁移旧PASS。章3000–6000 LN、剧情默认500–2500、称呼与审批规则沿用。
